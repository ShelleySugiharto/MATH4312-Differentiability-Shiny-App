### MATH 4312 Project 3: Interactive Derivative App

The app determines if a function is differentiable. The user can adjust, a, the point of differentiation, and, h, the increment to see where f(x) is differentiable.
The link to the app: https://connect.posit.cloud/shelleysugiharto/content/01a0fa1a-e584-bd60-7f98-1968e501ce1d

Another way to run the app is to do so manually, by downloading the app.R script and hitting "Run App" (top right).
